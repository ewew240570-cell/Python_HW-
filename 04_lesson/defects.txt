DEFECTS REPORT — StringUtils
==========================

Проект: Python_HW / lesson4

---------------------------------------
1. Метод capitalize — некорректная обработка None
---------------------------------------
Описание дефекта:
При передаче None метод вызывает встроенный метод capitalize у объекта None, что приводит к исключению AttributeError.

Шаги для воспроизведения:
1. Вызвать utils.capitalize(None)

Фактический результат:
AttributeError: 'NoneType' object has no attribute 'capitalize'

Ожидаемый результат:
Либо понятное исключение TypeError с сообщением о неверном типе аргумента,
либо безопасная обработка None (например, возврат пустой строки).

Статус: дефект
Серьёзность: средняя
Приоритет: средний


---------------------------------------
2. Метод trim — некорректная обработка None
---------------------------------------
Описание дефекта:
При передаче None метод вызывает string.startswith(), что приводит к AttributeError.

Шаги:
1. Вызвать utils.trim(None)

Фактический результат:
AttributeError: 'NoneType' object has no attribute 'startswith'

Ожидаемый результат:
Проверка входного параметра и выброс TypeError или другое контролируемое поведение.

Статус: дефект
Серьёзность: средняя
Приоритет: средний


---------------------------------------
3. Метод contains — некорректная обработка None в параметрах
---------------------------------------
Описание дефекта:
Метод вызывает string.index(symbol), что приводит к AttributeError, если string или symbol равны None.

Шаги:
1. utils.contains(None, "a")
2. utils.contains("abc", None)

Фактический результат:
AttributeError

Ожидаемый результат:
Проверка входных параметров и выброс TypeError или возврат False.

Статус: дефект
Серьёзность: высокая
Приоритет: высокий


---------------------------------------

Фактический результат:

Проверка входных параметров и выброс TypeError или безопасная обработка.

Статус: дефект
Серьёзность: высокая
Приоритет: высокий

5. Метод trim — удаляет только обычный пробел " "
---------------------------------------
Описание дефекта:
Метод не удаляет другие виды whitespace: \t, \n, \r, неразрывный пробел.

Шаги:

Фактический результат:

Ожидаемый результат:
"skypro"

Серьёзность: низкая
Приоритет: низкий
